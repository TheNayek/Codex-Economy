# Changelog

## 0.2.0 — community preview

- Add dated, source-backed credit estimates with explicit token assumptions,
  workload examples and retry costs; distinguish them from subscription quota
  and measured savings.
- Make Astra high the ordinary open-ended owner and use bounded Luna and Sol
  agents where delegation helps. Add DIRECT and CONTINUITY routes; reserve DEEP
  xhigh and sol-worker-high for explicit, supported choices.
- Align the public installer, role names, English/Spanish onboarding, and
  compatibility guidance. Custom init keeps DEFAULT high when DEEP is xhigh.
- Retire the former implementer role only when its installed file is still
  owned and unchanged; keep collision and rollback protections.
- Add a hypothetical owner-and-workers credit example that includes planning
  and review overhead, without treating credits as subscription quota.

## 0.1.0 — community preview

- Portable initialization with an explicit target home and ignored local manifest.
- Agent installation runbook and configurable model/effort choices at initialization.
- Original three task-oriented profiles: QUICK, DEFAULT, DEEP; balanced DEFAULT owner.
- The public preset preserves sandbox, approvals, web search, and root preferences.
- Read-only doctor with explicit model-availability uncertainty.
- Reversible native profile/agent configuration and scoped configuration backups.
- Read-only usage observation with attribution and deduplication checks.
- Public distribution assembled from an explicit allowlist without private history.
- English/Spanish onboarding, measurement methodology, MIT license, contribution
  and security guidance, and offline CI for Windows/Linux/macOS.

This preview grows from a personal Windows installation. Personal runtime
audits are deliberately not shipped. Offline correctness, current-client
routing, and demonstrated quota savings are different claims; no controlled
savings benchmark is included.
